<objective>
## Goal
Reemplazar el envío 1-a-1 por WhatsApp (mensaje personalizado + `wa.me` sin destinatario, que obliga a buscar cada contacto) por un botón único de envío masivo: un tap → hoja de compartir del sistema → seleccionar varios contactos de WhatsApp → enviar el mismo mensaje/link a todos. Y agregar un panel de moderación en el admin para listar y borrar las confirmaciones públicas (incl. colados).

## Purpose
Resuelve el problema concreto del usuario: hoy mandar la invitación a 100+ invitados es tedioso porque hay que abrir WhatsApp y volver a buscar cada contacto a mano. Con el link genérico del plan 01-01 ya funcionando, este plan habilita el envío masivo y el control (moderación) desde el backoffice.

## Output
- `whatsapp.ts` reescrito: mensaje genérico (sin nombre/cupos) + link a la landing, con `shareInvite()` basada en Web Share API y fallback.
- Botón "Compartir invitación por WhatsApp" en el header del dashboard admin.
- `GuestTable`/`GuestForm`: se retira el botón de WhatsApp 1-a-1 (obsoleto con el modelo nuevo).
- `PublicRSVPPanel`: panel de moderación de `public_rsvps` (listar + borrar).
</objective>

## AC-1: Envío masivo con un tap
```gherkin
Given el admin abre el dashboard en su teléfono (HTTPS)
When toca "Compartir invitación por WhatsApp"
Then se abre la hoja de compartir del sistema y, al elegir WhatsApp, puede
     seleccionar varios contactos y enviarles el mismo mensaje + link a la landing
And el mensaje es genérico (no incluye nombre ni cupos de un invitado puntual)
```

## AC-2: Fallback fuera de la Web Share API
```gherkin
Given un entorno sin navigator.share (ej. desktop)
When el admin toca "Compartir invitación por WhatsApp"
Then se usa un fallback razonable (ej. abrir wa.me/?text= con el mensaje, o copiar
     el mensaje+link al portapapeles con aviso)
And nunca queda sin feedback
```

## AC-3: Panel de moderación de confirmaciones públicas
```gherkin
Given hay confirmaciones en public_rsvps
When el admin ve el dashboard
Then aparece un panel que lista nombre, asiste/no, cantidad y fecha de cada confirmación
And puede borrar una confirmación (con confirmación previa) — útil para colados
And tras borrar, la lista se actualiza
```

## AC-4: Retiro del envío 1-a-1 obsoleto
```gherkin
Given el modelo nuevo usa link genérico
When se revisa GuestTable / GuestForm
Then ya no está el botón de WhatsApp por-invitado con mensaje personalizado
And no quedan referencias muertas a buildInviteMessage/getWhatsAppShareUrl del modelo viejo
```
